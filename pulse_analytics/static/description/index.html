Pulse Analytics

Privacy-first web analytics for your Odoo website, in one module.

It sets no cookies, stores no personal data, and does no fingerprinting. The script it adds to your pages is under 3 KB. Built by Ciphera BV, a company in Belgium — your data is hosted in Switzerland.

How it works

Install the module. There is nothing to configure — no settings screen, no API key to paste in.

The tracking tag is added to every page your Website app serves, automatically. It reads the domain from each visitor's own browser, which is correct for a site served on one domain.

Create a free account, add your site, and your dashboard starts showing visitors as they arrive.

Pulse Analytics measures pageviews, referrers, countries, devices, time on page and scroll depth, plus the goals, funnels and campaigns you set up — in one dashboard. Visitors whose browser sends Do Not Track or Global Privacy Control are not counted at all.

What this module does, completely

One <script> tag, added to every public page the Website app renders. The logged-in Odoo backend never carries it — it cannot, by construction, since the backend is a client-rendered application this module's view never touches. The public login page does carry it, the same way Odoo's own built-in "Custom Code" field would reach that page too; that is expected, not a leak.

There is no settings screen, because this module is written entirely in XML, with no Python beyond the one empty file every Odoo module requires — so it also installs on Odoo Online, which does not allow third-party modules that contain custom Python.
