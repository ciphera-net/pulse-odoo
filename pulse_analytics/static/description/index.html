Pulse Analytics

Privacy-first web analytics for your Odoo website, in one module.

Pulse Analytics sets no cookies and never stores IP addresses. The script it adds to your pages is under 3 KB. Ciphera BV, a company in Belgium, builds it, and your data is hosted in Switzerland.

How it works

Install the module. There is nothing to configure: it has no settings screen and needs no API key.

The module adds the tracking tag to every page your Website app serves. It reads the domain from each visitor's own browser, which is right for a site served on one domain.

Create a free account at pulse.ciphera.net, add your site, and your dashboard starts showing visitors as they arrive.

Pulse Analytics counts pageviews, referrers, countries, devices, time on page and scroll depth, plus the goals, funnels and campaigns you set up, in one dashboard. It does not count visitors whose browser sends Do Not Track or Global Privacy Control.

What this module does, completely

The module adds one <script> tag to every public page the Website app renders. The logged-in Odoo backend never carries it. It cannot, because the backend is a client-rendered application that this module's view never touches. The public login page carries it too, the same way Odoo's own built-in "Custom Code" field would.

There is no settings screen, because this module is written entirely in XML, with no Python beyond the one empty file every Odoo module requires. That also lets it install on Odoo Online, which does not allow third-party modules that contain custom Python.
